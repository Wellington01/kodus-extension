# Change Log

All notable changes to the "kodus-extension" extension will be documented in this file.

## [0.0.1] - 2024-01-XX

### Added

- Initial release of Kodus Development Tools
- Quick Actions: Format JSON, Convert Case, Insert Timestamp, Insert Snippet
- MCP Tools integration for code analysis and documentation generation
- GitHub Integration for PR sync and management
- Webview UI with Lit Element components
- VSCode theme integration
- File reference detection for Kodus validation
- Comprehensive Cursor Rules for development workflow

### Features

- **Quick Actions**: Format JSON, Convert Case, Insert Timestamp, Insert Snippet
- **MCP Tools**: Code Analysis, Documentation Generator
- **GitHub Integration**: PR Sync, Create PR, Auto Merge
- **Modern UI**: Lit Element components with VSCode theme integration
- **Developer Experience**: Cursor Rules, File References, TypeScript support

### Technical Details

- Built with TypeScript and ESBuild
- Uses Lit Element for lightweight Web Components
- Integrates with VSCode themes via CSS Custom Properties
- Implements proper extension lifecycle management
- Includes comprehensive error handling and user feedback
- Follows VSCode extension best practices

### Documentation

- Complete README with installation and usage instructions
- UI Design documentation
- Configuration schemas for validation
- Cursor Rules for AI-assisted development
